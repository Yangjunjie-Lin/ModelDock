# ModelDock Provider Marketplace policy set

This directory is the Marketplace-specific contractual and operational policy set. Each production supplier release records the policy version `marketplace-launch-2026-08-21`; changing a substantive term requires a new version and a new launch review. These repository documents are product controls and contract schedules, not evidence that any supplier has signed them.

- [Marketplace service agreement](service-agreement.md)
- [SLA rules](sla-rules.md)
- [Supplier policy](supplier-policy.md)
- [Settlement policy](settlement-policy.md)
- [Dispute policy](dispute-policy.md)
- [Data processing addendum](data-processing-addendum.md)
- [Provider publication standard](provider-publication-standard.md)
- [Launch acceptance and operations](launch-acceptance.md)

No production payout adapter may be enabled merely because these documents exist. The supplier-specific contract, tax, payment-destination, and security reviews must each carry administrator-approved evidence in `supplier_payout_readiness_review`.
