# Provider 与模型披露（产品事实草案）

> **待律师审核 / PENDING COUNSEL REVIEW — 非最终法律披露或 Provider 背书。**

ModelDock 是统一网关，不是所有上游模型的开发者。模型可能由 OpenAI、Anthropic、
Google、DeepSeek、阿里云、Moonshot、智谱、OpenRouter 或其他由运营方实际审核并
启用的 Provider 提供。仓库内的种子记录不等于已签合同、已获转售权或已在任何地区
可售。

公开模型和 Provider 目录是购买/调用前的事实源，至少展示：实际 Provider、模型标识、
能力、上下文窗口（未知时为空）、技术/商业状态、客户允许/禁止地区、数据处理地区、
数据保留政策、条款版本、紧急禁用状态和有效价格。`available=false` 必须阻止购买和
调用，不得只显示一个装饰性警告。

智能路由只会在当前组织/项目获准且满足合同、地区、数据、能力、容量和定价条件的
候选中选择。物理路由的备用凭据组仅在任何上游尝试前使用。尝试开始或 SSE 输出后
不会切换 Provider 重放。客户如要求固定 Provider/地区，应使用明确路由和组织政策，
并由合同确认可用性。

最终页面必须链接各 Provider 的官方条款/隐私/模型说明（由律师确认链接和描述），
说明生成内容风险、内容标识和投诉机制，并避免“绝对稳定”“无条件全球可用”“完全
合规”或无法证明的最低价比较。
