# 可接受使用政策（草案）

> **待律师审核 / PENDING COUNSEL REVIEW — 非最终法律文件，不构成法律意见。**
> 最终版本还必须纳入目标市场法律和各 Provider 的有效使用政策。

## 明确禁止

- 自动或批量创建 Provider/消费者账号；
- 自动取验证码、临时邮箱注册、OTP/邮箱验证绕过；
- CAPTCHA/Turnstile 求解、外包、抑制或绕过；
- 浏览器指纹规避、消费者 Cookie/会话池、私有 Web Token 抽取或重放；
- 通过代理、IP、身份、项目、账号或凭据轮换规避限流、风控、封禁或地区限制；
- API Key 买卖、未授权共享、盗用或跨组织凭据池；
- 自动领取试用、促销、推荐、结账利益或新用户权益；
- 隐瞒流量来源、客户、项目或用途；
- 违法、有害、侵权、欺诈、恶意软件、骚扰或规避安全控制的用途；
- 将 Provider Key、支付密钥、个人隐私或其他秘密放入公开日志/工单。

## 允许边界

管理员可以导入少量已由其合法取得并获授权的官方 Provider API 凭据；这不是账号注册
或凭据交易。普通企业正向代理可用于获批网络连接，但不得用于规避 Provider 控制。
BYOK 仅供凭据所有组织使用，仍受合同、地区、模型和安全政策约束。

平台可以冻结 Key、限制请求、暂停主体、保留审计证据并将疑似事件进入人工审核。
最终申诉、通知、执法协作和终止标准必须由律师批准。
