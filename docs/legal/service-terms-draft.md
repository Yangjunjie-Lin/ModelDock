## 1. 服务范围

ModelDock 提供统一的 OpenAI-compatible API 网关、项目 API Key、模型路由、
用量和计费记录、订阅权益及客户自有 Provider Key（BYOK）管理。可用模型、Provider、
地区、价格和状态以请求或购买时的运行时公开目录为准。平台不承诺所有 Provider、
模型、地区或功能始终可用，也不承诺最低价格或不中断服务。

## 2. 账号与组织

用户应提供其有权使用的邮箱和组织信息，保护登录凭据及一次性显示的 `rdk_*` API
Key，并及时撤销泄露凭据。账号注册模式可能为关闭、邀请制或公开。企业方案需要
单独合同和人工审核，不因网页提交而自动生效。

## 3. 费用

购买前页面分别显示订阅费、Token 按量费、支付渠道或平台服务费、赠送额度、税费
口径、退款摘要及模型/地区可用性。订阅只购买明确列出的有限产品权益；Token 调用
始终按量单独计费。金额以不可变价格快照和资金账本为结算证据；兼容字段
`estimated_cost` 不是应付账款依据。税是否包含及发票能力必须以经审核的地区条款
为准。

## 4. Provider 与地区

每次调用均受 Provider 合同/转售状态、禁用开关、允许地区、数据处理地区、模型能力、
容量和客户组织政策约束。技术健康不等于商业授权。Provider 失败、限流或合同变化
可能导致模型不可用；平台不会通过代理、账号或身份轮换绕过 Provider 控制。

## 5. 使用限制

用户必须遵守经审核的可接受使用政策、适用法律和 Provider 条款。禁止账户批量注册、
验证码/CAPTCHA 绕过、消费者会话池、API Key 买卖、地区或限流规避、侵害他人权利
及其他被政策禁止的活动。

## 6. 暂停与终止

系统可依据安全、滥用、付款风险、法律要求、Provider 合同或紧急禁用开关暂停账号、
Key、组织、路由或 Provider。最终通知、申诉、数据导出、结算和终止程序必须由律师
结合目标市场审核后写入。

适用法、争议解决、消费者强制性权利、条款变更和通知机制。
