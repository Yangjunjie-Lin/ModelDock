# 退款规则（产品能力草案）

> **待律师审核 / PENDING COUNSEL REVIEW — 非最终法律文件，不构成退款承诺。**
> 地区消费者法、渠道规则、税务处理、时限和例外必须由律师/财务批准。

购买前的运行时 `commercial_terms` 必须披露退款摘要和审核状态。当前系统区分：

- 已充值但未使用的现金归属；
- 已产生服务用量的 Token 费用；
- 不可退的赠送额度；
- 独立的订阅费；
- Provider 已发生且不可追回的成本；
- 支付渠道状态和退款订单。

退款不是通过修改余额或删除账本完成。用户提交退款申请后，管理员以明确理由审核；
获批退款使用幂等退款订单、新的反向钱包交易和新的平衡会计分录，并保留与原充值/
订阅/请求的追踪关系。当前支付子系统只支持全额渠道退款；不得据此推断所有商业场景
均无条件全额退款。赠送额度保持独立且不可转换为现金。

最终页面必须填写：适用订单类型、可申请期限、已使用服务的计算方式、订阅取消与
续费规则、支付渠道费/税的处理、审核和到账时限、拒绝/申诉流程、法定退款权利、
拒付处理及真实联系渠道。占位：`[律师和财务批准的退款条件]`。
