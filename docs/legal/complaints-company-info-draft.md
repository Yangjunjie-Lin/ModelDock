# 投诉举报、联系与公司信息（占位草案）

> **待律师审核 / PENDING COUNSEL REVIEW — 非最终法律送达或公司披露。**

## 产品内渠道

登录用户可通过 `/api/console/support/tickets` 创建支持工单，通过
`/api/console/reports` 提交滥用、内容、隐私或其他举报。提交时只提供必要的、已脱敏
的请求 ID/订单 ID；不得发送 API Key、Provider Key、支付凭据、Cookie 或不必要的
个人信息。安全漏洞应使用经运营方批准的私密安全渠道，而不是公开状态页。
